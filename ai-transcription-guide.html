Guide: AI transcript organizer

Organize a voice transcript with AI. Keep every word.

This guide shows how to record your thoughts, make a transcript, and use an AI tool to put the transcript in a logical order. A steering file tells the AI to move your words, not to change them. The steering file works with Claude, ChatGPT, Gemini, and other AI tools.

AnyAI tool or agent

How the workflow operates

The workflow has five steps. Do the first step one time. Do the other steps each time that you record.

  • 1Add the steering file
  • 2Record
  • 3Make a transcript
  • 4Organize
  • 5Check

What a steering file is

A steering file is a set of written instructions for an AI tool. The AI reads the file before it reads your transcript. Other names for it are "custom instructions", "system prompt", "project instructions", and "agent instructions".

Without a steering file, most AI tools rewrite text. They correct grammar, make sentences shorter, and replace words. This steering file stops that. The AI can move your sentences and add headings. It cannot change your words.

Step 1: Add the steering file to your AI tool

Copy the steering file below. Then follow the instructions for your AI tool.

Steering file
# Steering file: transcript organizer

## Your task
You organize transcripts of spoken words. You do not edit them.
The user gives you a transcript. You give back the same words in a logical order, with headings.
If the message is only a transcript, do this task. The user does not need to give other instructions.

## Rule 1: Keep the author's words
This rule is the most important rule. It has priority over all other instructions.
- Use only the words in the transcript.
- Do not add words to a sentence.
- Do not remove words from a sentence. The only exception is the "Filler words" option below.
- Do not change a word. Do not use a synonym.
- Do not correct grammar, spelling, or word choice.
- Keep the words of each sentence in their original order.
- Do not summarize, paraphrase, explain, or shorten the text.
- Keep incomplete sentences as they are.
- If the author says the same thing two times, keep the two sentences.

## Rule 2: What you can change
You can do only these things:
1. Move sentences and paragraphs to a different position.
2. Put sentences about the same topic together.
3. Add headings.
4. Add paragraph breaks.
5. Add punctuation and capital letters where the transcript has none. Do not change a word to do this.
6. Change a spoken list into a bulleted list. Keep all the words of each item.

## Rule 3: How to find the logical order
1. Read the full transcript before you start.
2. Find the main topics.
3. Put the topics in a logical order. Put background and context first. Put the main points next. Put decisions, actions, and open questions last.
4. In each topic, put the sentences in a logical order. If a sentence depends on a different sentence, put it after that sentence.
5. Keep a story or an example together, in its original order. Do not divide it.
6. If a sentence does not fit a topic, put it under the heading "Other points".
7. If the user gives a purpose (for example, "this is for a blog post"), use the purpose to choose the order of the topics. Rule 1 always applies.

## Rule 4: Headings
- Use words from the transcript in the headings when possible.
- Keep each heading short: 2 to 8 words.
- Use "##" for main topics and "###" for subtopics.

## Rule 5: Do not add other text
- Headings and the markers in Rules 6 and 7 are the only text that you write.
- Do not add an introduction, a summary, or a conclusion.
- Do not add comments, advice, or questions before or after the result.

## Rule 6: When you are not sure
- If a word looks like a transcription error, keep the word. Write [?] after it.
- Do not guess a correction.
- If you cannot move a part of the text without a change to its words, keep that part in its original order.

## Rule 7: Long transcripts
- Include all of the transcript in the result. Do not skip text.
- If the result is too long for one message, stop at the end of a section and write [CONTINUES].
- When the user writes "continue", give the next part.

## Options
The user can change these settings.
- Filler words: KEEP
  (KEEP: keep all filler words. REMOVE: remove only "um", "uh", "er", and "ah". Remove no other words.)
- Headings: YES
  (YES: add headings. NO: do not add headings. Use paragraph breaks only.)

Note: Menu names in AI tools change often. Some functions also need a paid plan. If you cannot find a function, use the method in "Any other AI tool".

Claude

  1. Open Claude (claude.ai or the Claude app).
  2. Make a new project. Give it a name, for example "Transcript organizer".
  3. Open the project instructions. Paste the steering file.
  4. Start each new transcript as a new chat in this project.

ChatGPT

  1. Open ChatGPT (chatgpt.com or the ChatGPT app).
  2. Make a new project. Open the project settings.
  3. Paste the steering file into the instructions.
  4. Start each new transcript as a new chat in this project.

You can also make a custom GPT. Paste the steering file into its "Instructions" field.

Gemini

  1. Open Gemini (gemini.google.com or the Gemini app).
  2. Make a new Gem. Give it a name, for example "Transcript organizer".
  3. Paste the steering file into the "Instructions" field. Save the Gem.
  4. Start each new transcript as a new chat with this Gem.

AI agents that read files

Claude Code, Codex, Gemini CLI, Cursor, GitHub Copilot, and other agents read an instructions file in your work folder.

  1. Make a folder for your transcripts.
  2. Save the steering file in that folder. Use the file name that your agent reads:
    • CLAUDE.md for Claude Code
    • GEMINI.md for Gemini CLI
    • AGENTS.md for Codex, Cursor, GitHub Copilot, and most other agents
  3. Save each transcript in the folder as a text file, for example 2026-11-10-transcript.txt.
  4. Tell the agent: "Organize 2026-11-10-transcript.txt. Save the result as 2026-11-10-organized.md."

Any other AI tool

  1. Look in the settings for "custom instructions", "system prompt", or "instructions". If the tool has one of these, paste the steering file there.
  2. If the tool does not have one of these, paste the steering file at the start of each new chat. Paste the transcript after it, in the same message.

Step 2: Record your thoughts

  • Use the voice recorder app on your phone or computer.
  • Record in a quiet room. Hold the microphone near your mouth. Clear audio gives a better transcript.
  • Speak in your usual way. You do not have to speak in a logical order. The AI does that in Step 4.
  • You can record more than one audio file on the same subject. Put the transcripts together in Step 3.

Step 3: Make a transcript

Caution: Your audio can contain private information. Before you use a tool, read its privacy settings. Some tools keep your data or use it to train AI models. A tool that operates only on your device keeps the audio on your device.

Use one of these tools to change your audio into text:

  • iPhone: The Voice Memos app and the Notes app can make a transcript of an audio file (iOS 18 and later).
  • Android: On Pixel phones, use the Recorder app. Many other Android phones have a recorder app that makes transcripts.
  • Mac or Windows: Use the Transcribe function in Microsoft Word (Microsoft 365). On a Mac, MacWhisper makes transcripts on your computer.
  • Calls: Zoom, Google Meet, and Microsoft Teams can make a transcript of a call.
  • An AI tool: Some AI tools, for example Gemini, accept audio files. Upload the audio and write: "Write a word-for-word transcript of this audio. Do not change or remove words." Use this transcript in Step 4, in a new chat.

When you have the transcript, do these steps:

  1. Copy all of the transcript text.
  2. Save a copy of the original transcript. You use it in Step 5 to check the result.

Step 4: Organize the transcript

  1. Open a new chat in your project, Gem, or custom GPT.
  2. Paste the full transcript.
  3. Optional: Before the transcript, write the purpose in one line, for example "This is for a blog post." The AI uses the purpose to choose the order of the topics.
  4. Send the message. You do not have to write other instructions.
  5. If the result stops with [CONTINUES], write "continue". Do this until the AI gives all of the result.

Step 5: Check the result

Warning: AI tools can make errors, also with a steering file. Always check the result before you use or share it.

  1. Compare the word counts. Paste the original transcript and the result into a word counter, for example Tools > Word count in Google Docs. The result has a small number of extra words from the headings. If the result has fewer words than the transcript, text is missing. (This is not true if you set "Filler words" to REMOVE.)
  2. Select three to five sentences in the result. Find each sentence in the original transcript. Make sure that the words are the same.
  3. Find the words with [?]. Correct them yourself.

Optional: Use AI to check the result

Open a new chat without the steering file. Copy the prompt below. Paste the original transcript and the result into it. Send it.

Problems and solutions

The AI changed my words

  1. Make sure that the steering file is in the project, Gem, or instructions settings. A steering file in an old chat does not apply to a new chat.
  2. Start a new chat. Paste the transcript again.
  3. If the problem continues, write: "Obey Rule 1. Use only my words. Do the task again."

The AI added a summary or comments

Write: "Obey Rule 5. Remove all text that is not a heading or a sentence from the transcript."

The result stops before the end

Write "continue". If the AI does not continue, divide the transcript into two parts. Organize each part in a new chat.

The transcript has incorrect words

Transcription tools sometimes write a word incorrectly. The steering file tells the AI to keep these words and to put [?] after them. Correct these words yourself in the result.

Change the steering file

The "Options" section at the end of the steering file has two settings. To change a setting, edit the word in capital letters. Then save the steering file again in your AI tool.

  • Filler words: KEEP or REMOVE. With REMOVE, the AI removes only "um", "uh", "er", and "ah".
  • Headings: YES or NO. With NO, the AI uses paragraph breaks only.

Do not change Rule 1. Rule 1 is the rule that keeps your words the same.
